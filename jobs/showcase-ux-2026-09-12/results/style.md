# Style implementation

Updated `apps/web/src/styles.css` for the public showcase presentation.

- Preserves the navy and teal brand palette while increasing supporting text to readable 13–17px sizes.
- Adds keyboard-visible focus treatment, 40px+ controls, safe wrapping for long IDs and content, and reduced-motion support.
- Keeps mobile navigation text visible in horizontally scrollable navigation; split layouts stack at tablet widths.
- Adds compatible presentation hooks for showcase hero, featured activity, contribution links, reviewer links, and unknown presence state.
- Prevents horizontal page overflow down to 320px and stacks dense controls on narrow screens.
